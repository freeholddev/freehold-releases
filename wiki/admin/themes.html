Themes

A theme is a second set of drawings and materials that a settlement builds with instead of Freehold's own. It is a datapack with a namespace of its own — nordic, say — and it changes how the buildings look, never what they do. A theme holds for one settlement, and each settlement can have another.

What a theme holds

A theme may leave gaps: whatever it does not draw, the settlement builds from Freehold's own drawings. A theme can be as small as a single file. There are three ways to make one, each of use on its own:

  1. Recolour without building: one file, data/<theme>/material_class/wood.json (or stone, masonry, ground), replaces the wood or the stone of every building — see Recolouring only.
  2. Rebuild a building in the game: set out a template, rebuild it, export it — see Making a theme. This is the main way.
  3. Edit the drawing by hand: the export also writes the drawing as text, which can be edited further — see For the advanced.

A theme is loaded as soon as its namespace holds a drawing or a material class; there is no file that announces it. Where its files lie:

PathWhat it is
data/<theme>/structure/<building>/<version>.nbtThe blocks of one version of a building
data/<theme>/blueprint/<building>.jsonWhere its markers, its foundation and its versions are
data/<theme>/blueprint_source/<building>/<version>.fhbThe drawing as text, for whoever works on the theme; the game does not read it
data/<theme>/material_class/<class>.jsonIts wood, stone, masonry or ground, by biome

Choosing a theme

The founder picks the theme when founding. With more than one theme loaded, the founding screen has a button Theme: … under the name field, which steps through the loaded themes; the world's default is picked to begin with. Freehold's own theme is called Freehold. With a single theme loaded, or with the choice switched off, the screen shows no button — see Founding a settlement.

  • A theme from a datapack shows under its namespace, because a datapack brings no language file. For a nicer name, ship a resource pack with the key freehold.theme.<namespace>.
  • The game rule freehold:theme_choice, on by default, decides whether the founder chooses. When off, every new settlement is founded in the world's default — see Game rules.

Changing a theme

A theme acts on what is built; what stands keeps its blocks. An operator changes the theme of a settlement with /freehold theme set. From then on every new building and every upgrade is built in the new theme. A building whose drawing the new theme has differently counts as standing in an older version of its drawing: the settlement no longer repairs it by itself, and the button Lift to current drawing on the buildings tab rebuilds it in the new theme, for nothing.

A theme may draw a building taller or lower than the one that stands. Until such a building is lifted, it takes up the higher of the two heights — for its protection, its demolition and the windmill's open stand. Lifting rebuilds that whole space, so in a lower theme the upper layers of the old building go.

Installing a theme

Put the datapack folder or zip into <world>/datapacks/ and run /reload. /freehold theme list then shows it. A theme someone has made in the game lies there already — the export writes it into that folder.

Commands

Every /freehold theme … command needs operator rights (level 2). They answer in English.

CommandWhat it does
/freehold theme listThe loaded themes, each with how many drawings and material classes it holds, the world's default, and every settlement with its number, name and theme
/freehold theme default [theme]Reads or sets the theme new settlements are founded in, for the whole world; freehold to begin with
/freehold theme set <freehold> [theme]Reads or sets the theme of one settlement, by its number; the numbers are suggested as you type
/freehold theme template <theme> <building> [version]Sets out a building to rebuild — see Making a theme
/freehold theme export <theme> <building> <version> <x> <y> <z> [height] [blocks]Reads the rebuilt building back into the theme's datapack, as many layers high as height says (at least 2; without it, as high as the theme's other versions of the building or else the template) — see Making a theme

The number of a settlement is shown by /freehold theme list, one line each — “1 Hochstadt: freehold”. The numbers count the settlements of the dimension the command runs in; for a settlement in another dimension, run it there or with execute in … run ….
